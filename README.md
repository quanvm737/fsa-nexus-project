# Nexus Web

Enterprise Frontend Application built with **Next.js 15**, **TypeScript**, **TailwindCSS**, and **Feature-Sliced Design (FSD)**.

## Getting Started

1. Cài đặt dependencies:
\\\ash
npm install
\\\

2. Khởi chạy môi trường phát triển:
\\\ash
npm run dev
\\\
Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt.

3. Build cho Production:
\\\ash
npm run build
\\\
